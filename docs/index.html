                        백업

                        브라우저 기록 삭제·기기 변경 전 백업 권장

                        수집

                        • 출처: 네이버 뉴스 검색 API
                        • 검색어: 도시계획·정비사업·주택·신도시·교통·도시개발·도시행정·도시환경 관련 100여 개
                        • 주기: 하루 6회(7·10·13·16·19·22시). 실제 실행은 몇 분~수십 분 늦을 수 있음
                        • 저장 범위: 제목·요약·원문 링크(본문 미저장)

                        분류

                        • 지역: 서울 25개 구·동 이름, 1·2·3기 신도시, 경기·인천 시 이름 사전 기준. 비수도권 지명만 있는 기사 제외, 지명 없는 기사는 '전국·정책'
                        • 분야: 분야별 낱말 사전 점수(제목 2점, 요약 1점). 어느 분야에도 해당하지 않는 기사 제외
                        • 주요 이슈: 제목 낱말이 2개 이상 겹치는 기사끼리 묶음. 언론사 3곳 이상이 다룬 묶음만 표시, 순위는 다룬 언론사 수
                        • 오피니언: 제목 머리말([사설], [시론], [기자수첩] 등) 기준
                        • 시간대: 기사 게시 시각 기준

                        모두 규칙 기반(AI 미사용)이라 잘못 분류된 기사가 섞일 수 있음

                        논문

                        • 출처: OpenAlex(공개 학술 데이터베이스)
                        • 대상: config/journals.json의 학술지(기본 해외 18곳·국내 4곳)
                        • 범위·주기: 최근 90일, 하루 1회 갱신
                        • 원문: PDF 미저장. 무료 공개 원문만 바로 연결, 유료 원문은 DOI로 연결(교내망·도서관 로그인 필요)
                        • 국내 학술지: 영문 제목으로 수록, 최신호 반영이 두세 달 늦음

                        연구 동향

                        • 범위: 관심 학술지, 도시·계획 분야, 도시 × 머신러닝, 건축 분야, 건설 분야(OpenAlex 세부분야·키워드 기준)
                        • 비교: 최근 1년(두 달 전까지)과 그 전 1년의 주제·키워드별 논문 수, 전체 논문 대비 비중 변화
                        • 키워드 지도: 원 크기 = 논문 수, 거리 = 같은 논문에 함께 붙은 정도, 색 = 비중 변화
                        • 주기: 7일마다 계산

                        용어·개념

                        • 사전: config/glossary.json의 도시 용어와 학술 개념(뜻·근거 법·관련 용어·문헌)
                        • 기사 속 용어: 선택한 날짜 기사 제목·요약에 나온 사전 용어를 셈. 다른 이름(예: 재초환)도 함께 셈
                        • 카드 학습·'알아요' 표시: 이 브라우저에만 저장, 백업 파일에 포함
                        • 법 개정으로 자주 바뀌는 수치(기준 금액·비율)는 사전에 넣지 않음

                        관심 필자

                        • config/people.json의 필자·인물이 나온 칼럼·인터뷰·인용 기사를 오피니언 탭 위쪽에 모음
                        • 지역·분야 거르기 없음. 처음 넣은 필자는 지난 1년 치를 한 번 거슬러 받음
